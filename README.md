# LASSO Optimization Algorithms Comparison & Analysis

# LASSO 回归优化算法收敛性对比分析

## 📖 项目简介 (Introduction)

本项目通过系统的数值实验，全面比较了多种优化算法及其变体在求解 **LASSO (Least Absolute Shrinkage and Selection Operator)** 回归问题时的收敛性能。研究不仅涵盖了经典算法，还深入分析了**动态策略**（如重启机制、参数调优）对算法性能的影响机制。

目标函数定义为：
$$\min_{\beta} \frac{1}{2n} \| y - X\beta \|_2^2 + \lambda \| \beta \|_1$$

## 🛠️ 实验设置 (Experimental Setup)

### 数据生成与实验设计
* **数据维度**: 样本量 $n=200$, 特征数 $p=50$
* **稀疏性设置**: 真实参数向量中仅前10个元素非零
* **正则化强度**: $\lambda = 0.1 \times \lambda_{\text{max}}$, 其中 $\lambda_{\text{max}} = \|X^Ty\|_\infty/n$
* **实验机制**: 独立重复实验 **100次**，确保统计显著性
* **基准真值**: 使用scikit-learn的Lasso求解器获得高精度 $f^*$ 参考值

### 可视化方案
* **细淡色线 (Cloud Traces)**: 单次实验轨迹，反映算法稳定性
* **粗实线 (Mean Performance)**: 平均收敛路径，表征期望性能
* **对数坐标**: y轴采用对数尺度，清晰展示收敛速率差异


## 🚀 实现算法与曲线含义

1.  **Coordinate Descent (BCD)**: 块坐标下降法
2.  **Huber Gradient Descent**: 基于 Huber 平滑逼近的梯度下降法
3.  **FISTA**: 快速迭代收缩阈值算法 (Nesterov 加速)
4.  **ADMM**: 交替方向乘子法 (包含参数敏感性分析)

### 1. 块坐标下降法系列 (Coordinate Descent)

**Coordinate Desc (红色实线)**
- **算法原理**: 每次迭代沿单个坐标方向进行精确最小化，利用LASSO问题的可分性结构
- **曲线特征**: 近乎垂直的快速下降，在20次迭代内达到机器精度
- **性能分析**: 收敛速度最快，方差最小，展现了坐标下降在稀疏优化中的统治地位

### 2. Huber梯度下降系列 (Huber Gradient Methods)

**Huber Gradient (浅绿色实线)**
- **算法原理**: 使用Huber函数平滑近似L1范数，采用固定步长的梯度下降
- **曲线特征**: 平缓的线性收敛，存在明显的收敛平台
- **局限性**: 平滑近似引入系统误差，无法精确收敛到真实最优解

**Huber Gradient (Accel) (森林绿实线)**
- **改进策略**: 引入Nesterov动量加速，提升收敛速率
- **曲线特征**: 相比基础版本收敛更快，但仍受限于平滑近似的固有偏差

**Huber Gradient (Accel + Restart) (深绿色虚线)**
- **动态机制**: 基于梯度条件的自适应重启策略
- **曲线特征**: 重启点处出现轻微"跳跃"，整体轨迹更加稳定
- **分析**: 重启策略在一定程度上缓解了动量累积导致的overshooting

### 3. FISTA系列 (Fast Iterative Shrinkage-Thresholding)

**FISTA (深蓝色实线)**
- **算法原理**: Nesterov加速的近端梯度方法，专为复合优化设计
- **曲线特征**: 典型的振荡收敛模式，呈现"波纹状"轨迹
- **机制分析**: 动量项导致算法在最优解附近来回穿越，是加速方法的固有现象

**FISTA (Restart) (蓝色虚线)**
- **重启条件**: 基于梯度内积的充分下降条件检测
- **曲线特征**: 有效抑制振荡，后期收敛更加平稳
- **权衡分析**: 牺牲部分前期速度换取更好的稳定性和鲁棒性

### 4. ADMM系列 (Alternating Direction Method of Multipliers)

**ADMM (rho=0.5) (橙色实线)**
- **参数设置**: 较小的惩罚参数，对偶更新步长较大
- **曲线特征**: 中等收敛速度，前期下降较快但后期放缓
- **分析**: 较小的rho可能导致原始可行性和对偶可行性的不平衡

**ADMM (rho=1) (品红实线) - 最优表现**
- **参数调优**: 在问题尺度下的最佳平衡点
- **曲线特征**: 快速且稳定的线性收敛，方差较小
- **理论依据**: 较好地平衡了原始残差和对偶残差的下降速率

**ADMM (rho=2) (青色实线)**
- **参数设置**: 中等偏大的惩罚参数
- **曲线特征**: 收敛速度略慢于rho=1，但仍保持良好性能
- **观察**: 过大的rho开始对收敛产生轻微抑制作用

**ADMM (rho=5) (紫色实线)**
- **参数设置**: 较大的惩罚参数，强调约束满足
- **曲线特征**: 收敛显著变慢，呈现"过度惩罚"现象
- **机制解释**: 大的rho值导致子问题求解的数值条件变差，更新步长过小

## 📊 系统性对比分析

### 1. 算法内部对比

#### Huber方法族比较
```
收敛速度: Accel+Restart ≈ Accel > 基础版本
稳定性: Accel+Restart > 基础版本 ≈ Accel
最终精度: 三者均受限于平滑近似误差
```
**结论**: 加速策略有效，但无法克服Huber方法在LASSO问题中的根本局限性

#### FISTA变体对比
```
收敛速度: FISTA ≈ FISTA(Restart) [前期] > FISTA(Restart) [后期]
稳定性: FISTA(Restart) >> FISTA
振荡幅度: FISTA显著大于带重启版本
```
**结论**: 重启策略用微小的速度代价换取了显著的稳定性提升

#### ADMM参数敏感性
```
（在 ADMM 算法中，惩罚参数 $\rho$ (rho) 是影响收敛效率的关键超参数。为了寻找最优解，我们对 $\rho$ 进行了敏感性测试，取值范围为 $\{0.5, 1, 2, 5\}$。）
性能排序: rho=1 > rho=2 > rho=0.5 > rho=5
稳定性: 所有参数下均表现稳定
参数影响: 收敛速度对rho值高度敏感
```
**结论**: ADMM的性能严重依赖于参数选择，需要仔细调优

### 3. 理论分析

#### 收敛机理差异
- **坐标下降**: 利用问题的可分性结构，每次更新都带来显著目标函数下降
- **近端梯度**: 通过软阈值算子精确处理非光滑项，保持稀疏性
- **Huber近似**: 平滑化导致稀疏性识别能力下降，收敛到近似解
- **ADMM**: 通过变量分裂将复杂问题分解为简单子问题

#### 动态策略效果评估
- **重启机制**: 在FISTA中效果显著，在Huber方法中效果有限
- **参数调优**: 对ADMM至关重要，对其他算法影响相对较小
- **加速技术**: 对一阶方法普遍有效，但可能引入振荡

## 🔬 关键发现

### 1. 性能主导因素
- **算法选择**比**参数调优**对最终性能影响更大
- **问题结构利用**是获得超线性收敛的关键（如坐标下降）
- **动态策略**需要在算法特性与问题结构间仔细权衡

### 2. 实用推荐指南

**首选方案**: Coordinate Descent
- 适用于中小规模稠密问题
- 无需复杂参数调优
- 收敛速度无可匹敌

**备选方案**: FISTA with Restart  
- 适用于大规模或分布式环境
- 良好的速度-稳定性平衡
- 实现相对简单

**特定场景**: ADMM (rho=1)
- 分布式计算框架
- 可分离结构的复杂问题
- 需要高精度解的场景

**研究用途**: Huber方法
- 平滑优化理论分析
- 梯度方法扩展研究
- 不推荐实际应用

### 3. 未来研究方向
- 自适应参数调整策略的自动化
- 混合算法设计（如坐标下降与加速方法的结合）
- 针对超大规模问题的随机变体
- 理论收敛速率与实证性能的深入关联分析
