# LASSO Optimization Algorithms Comparison & Analysis

# LASSO 回归优化算法收敛性对比分析

## 📖 项目简介 (Introduction)

本项目通过系统的数值实验，全面比较了多种优化算法及其变体在求解 **LASSO (Least Absolute Shrinkage and Selection Operator)** 回归问题时的收敛性能。研究不仅涵盖了经典算法（如 BCD、FISTA），还深入分析了**动态策略**（如重启机制）以及**关键参数**（如 ADMM 的惩罚参数 $\rho$）对算法收敛速率和稳定性的影响。

目标函数定义为：
$$\min_{\beta} \frac{1}{2n} \left\Vert y - X\beta \right\Vert_2^2 + \lambda \left\Vert \beta \right\Vert_1$$

## 🛠️ 实验设置 (Experimental Setup)

### 数据生成与实验设计
* **数据维度**: 样本量 $n=200$, 特征数 $p=50$
* **稀疏性设置**: 真实参数向量中仅前10个元素非零（稀疏度 20%）
* **正则化强度**: $\lambda = 0.1 \times \lambda_{\text{max}}$, 其中 $\lambda_{\text{max}} = \|X^Ty\|_\infty/n$
* **实验机制**: 独立重复实验 **100次**，以消除随机性干扰
* **基准真值**: 使用scikit-learn的Lasso求解器获得高精度 $f^*$ 参考值


### 可视化说明
* **细淡色线 (Cloud Traces)**: 记录单次实验的收敛轨迹，反映算法的稳定性与随机波动。
* **粗实线 (Mean Performance)**: 100 次实验的平均收敛路径，表征算法的期望性能。
* **对数坐标**: y 轴采用对数尺度 ($f(\beta^k) - f^*$)，清晰展示不同阶段的收敛速率差异。

## 🚀 实现算法(Implementation algorithm)

1.  **Coordinate Descent (BCD)**: 块坐标下降法
2.  **Huber Gradient Descent**: Huber 平滑化的梯度下降法
3.  **FISTA**: 快速迭代收缩阈值算法 (Nesterov 加速)
4.  **ADMM**: 交替方向乘子法 (不同惩罚参数)

## 🔍 核心分析：步长与参数敏感性 (Step Size & Parameter Sensitivity)

本实验重点探究了参数设置（可视作广义步长）对算法收敛行为的决定性影响。

### 1. ADMM 的惩罚参数 $\rho$ (Step Size Effect)
在 ADMM 中，$\rho$ 起到了类似步长的作用，控制着原始残差与对偶残差的平衡。从图中（橙、品红、青、紫四色线）可以清晰观察到：
* **过小参数 ($\rho=0.5$, 橙色)**：初期下降尚可，但由于对原始可行性 ($Ax+Bz=c$) 的约束力不足，导致后期收敛缓慢，曲线出现“拖尾”。
* **次优参数 ($\rho=2$, 青色)**：表现稳健，虽然收敛速度略慢于 $\rho=1$，但依然保持了极高的效率。这表明 ADMM 在最优参数附近具有一定的**鲁棒性 (Robustness)**——只要参数处于合理的数量级范围内（Near-optimal zone），算法就能保持良好的性能，不会因为参数微调而导致性能断崖式下跌。
* **过大参数 ($\rho=5$, 紫色)**：收敛速度最慢。过大的惩罚项使得子问题求解时变量变化被过度抑制（Over-penalized），每一步“迈不开腿”，严重降低了收敛效率。
* **最优平衡 ($\rho=1$, 品红)**：在当前问题尺度下，$\rho=1$ 恰好处于“甜点区”（Sweet Spot），实现了原始残差与对偶残差的最佳权衡，收敛最快且最稳定。

### 2. 动量步长的动态调整 (Restart Strategy)
对比 **FISTA (深蓝)** 与 **FISTA-Restart (蓝虚线)**，体现了动态策略的重要性：
* **无重启**：由于动量的累积，算法在到达谷底后往往会因为惯性冲过头，导致在最优解附近反复震荡。
* **带重启**：当检测到梯度方向与动量方向夹角为钝角时，强制重置动量。这相当于一种**自适应的步长截断**，以极小的计算代价消除了振荡，显著提升了后期的收敛精度。

## ⚔️ 算法综合性能对比 (Algorithm Comparison)

我们将各算法从收敛机制、速度及适用场景三个维度进行横向评测：

### 1、内部对比

#### Huber方法族比较
```
收敛速度: Accel+Restart ≈ Accel > 基础版本
稳定性: Accel+Restart > 基础版本 ≈ Accel
最终精度: 三者均受限于平滑近似误差
```
**结论**: 加速策略有效，但无法克服Huber方法在LASSO问题中的根本局限性

#### FISTA变体对比
```
收敛速度: FISTA ≈ FISTA(Restart) [前期] > FISTA(Restart) [后期]
稳定性: FISTA(Restart) >> FISTA
振荡幅度: FISTA显著大于带重启版本
```
**结论**: 重启策略用微小的速度代价换取了显著的稳定性提升

#### ADMM参数敏感性（为了寻找最优解，我们对 $\rho$ 进行了敏感性测试，取值范围为 $\{0.5, 1, 2, 5\}$。）
```
性能排序: rho=1 > rho=2 > rho=0.5 > rho=5
稳定性: 所有参数下均表现稳定
参数影响: 收敛速度对rho值高度敏感
```
**结论**: 在 ADMM 算法中，惩罚参数 $\rho$ (rho) 是影响收敛效率的关键超参数。

### 3. 深度总结
* **速度最快**: **Coordinate Descent (BCD)**。由于 LASSO 目标函数中 L1 正则项是可分离的，BCD 能求得解析解，每一步都是“精确下降”。在特征维度 $p$ 不大时，它是绝对的首选。
* **潜力之星**: **ADMM**。虽然在单机小规模数据上不如 BCD 极致，但其最大的优势在于**可拆解性**。它能将复杂问题分解为简单子问题，非常适合处理分布式大数据或带有复杂约束的变体 LASSO 问题。
* **收敛效果关键**: 无论是 FISTA 的重启策略，还是 ADMM 的 $\rho$ 值选择，都表明**“自适应”或“精心调优”的参数设置**往往比算法本身的选取更能决定最终的收敛效果。


### 4. 理论分析

#### 收敛机理分析
- **坐标下降**: 利用问题的可分性结构，每次更新都带来显著目标函数下降
- **近端梯度**: 通过软阈值算子精确处理非光滑项，保持稀疏性
- **Huber近似**: 平滑化导致稀疏性识别能力下降，收敛到近似解
- **ADMM**: 通过变量分裂将复杂问题分解为简单子问题

#### 改进效果评估
- **动态调整**: 在FISTA中效果显著，在Huber方法中效果有限
- **参数调优**: 参数的调整对最终的收敛结果至关重要，
- **加速技术**: 对一阶方法普遍有效，但可能引入振荡


#### 性能主导因素
- **算法选择**：**算法选择**比**参数调优**对最终性能影响更大
- **问题结构**：**问题结构利用**是获得好的收敛结果的关键（对LASSO问题使用坐标下降）
- **动态策略**：需要在算法特性与问题结构间仔细权衡
